## Needs an owner decision

- SR1-http-timeouts — Decide whether to enforce header, request, and connection limits in the server.
- SR2-native-object-cap — Decide the native stored-object cap and its behavior on overflow.
- SR6-inline-body-cap — Decide whether inline body limits should be tied to server configuration.
- SR8-byte-weighted-limit — Decide whether API quotas should charge by request bytes.
- SR9-page-cap — Decide total reconciliation limits and cancellation of superseded passes.
- SR10-display-payloads — Decide whether to replace whole-AppState serialization across wasm.
- SR12-csp-connect-src — Decide the allowed WebSocket and HTTP origins for the web client.
- SR14-register-oracle — Decide whether an unused invite should be burned on an existing username.
- SR16-path-ipc — Decide whether same-user path-based IPC is acceptable or byte IPC is required.
- SRR-revocation — Decide the session list, revoke, and admin or cross-user revocation model.
- REV-soft-revoke — Decide whether device records need soft-revocation state instead of hard delete.
- SRR-user-scoping — Decide whether to add shared user-scoping helpers or CI enforcement.
- SRR-spki-pinning — Decide whether certificate or SPKI pinning is required.
- SRR-keychain-acl — Decide the required macOS keychain ACL for the IPC secret.
- SRR-login-timing — Decide whether login timing must be equalized further.
- SRR-client-created-at — Decide whether the server must issue the creation time used for TTL.
- SRR-username-lockout — Decide whether targeted username lockout is acceptable.
- SRR-auth-global — Decide whether the current distributed-flood behavior of the global auth bucket is acceptable.
- SRR-sig-provenance — Decide whether server-checked provenance is sufficient or signatures must provide E2E authenticity.
- CR1-key-rotation — Decide the data-key rotation and passphrase-change design.
- A3-confused-deputy — Confirm that same-origin scripts may request wasm decryption.
- A5-collab-not-e2e — Confirm that server-visible, server-modifiable collaboration is acceptable.
- A6-share-token — Decide share-token authentication, expiry, revocation, and write access.
- A7-anonymous-collab — Confirm that anonymous collaboration sockets and share pages are acceptable.
- R2-seq-trust — Decide the accepted sequence-time window and rejection policy.
- R10-collab-growth — Decide the document-size and per-connection byte budgets.
- SRL-meta-quota — Confirm metadata ciphertext remains charged and decide whether signed envelope bytes should also count; metadata landed in PR #1.
- OE-rollback-limits — Confirm the fresh-install and multi-revision rollback limits.
- OE-browser-anchors — Decide whether browser anchors need durable storage.
- OE-history-retention — Decide historical revision retention and purge semantics.
- SCH-anchor-growth — Decide native anchor expiry or indefinite retention.
- CAL-orphan-raw — Decide orphan raw-file cleanup and retention.
- CAL-pending-cancel — Decide cancellation and recovery for permanently pending imports.
- LSP-db-encryption — Decide between SQLCipher and application-level SQLite protection.
- LSP-schema-recreate — Decide how schema changes preserve object anchors.
