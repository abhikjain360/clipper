Direct dependencies held below their latest version

sha2: kept 0.10.9; latest 0.11.0.
  OPAQUE 4.0.1 still requires digest 0.10. The direct SHA-2 types must match
  its CipherSuite and TripleDh types. Separate transitive SHA-2 0.11 is
  used by the new Ed25519 and SQLx dependency families.

hmac: kept 0.12.1; latest 0.13.0.
hkdf: kept 0.12.4; latest 0.13.0.
  Their newer releases require digest 0.11 and cannot use the required
  direct sha2 0.10 types. Keeping their current majors avoids a second
  direct SHA-2 alias and a crypto integration change.

rand, renamed opaque-rand: upgraded 0.8.5 -> 0.8.8; latest 0.10.3.
  OPAQUE 4.0.1 requires Rand 0.8's RNG traits and OS RNG feature.
  The separate workspace Rand dependency was upgraded to 0.10.3.

rusqlite: upgraded 0.32.1 -> 0.39.0; latest 0.40.2.
  SQLx 0.9.0 requires libsqlite3-sys >= 0.30.1, < 0.38.0.
  Rusqlite 0.40.2 requires libsqlite3-sys ^0.38.1; Cargo cannot resolve
  two packages with the sqlite3 links key. Rusqlite 0.39 uses 0.37.0.
  The first cargo update failed on this conflict; the compatible pair
  resolved and passed the database and live tests.

uniffi: kept 0.31.2; latest 0.32.2.
  Both uniffi-bindgen-react-native 0.31.0-5 and its JavaScript runtime
  require UniFFI =0.31. The latest published React Native generator,
  0.31.0-6, still supports that line. UniFFI 0.32 changes external
  generator APIs and byte-buffer FFI behavior. Upgrading it safely
  requires a compatible React Native generator/runtime release.
  Source: packages/mobile-bridge/node_modules/uniffi-bindgen-react-native/Cargo.toml
  Latest generator: https://github.com/jhugman/uniffi-bindgen-react-native/blob/0.31.0-6/Cargo.toml
  Upstream: https://github.com/mozilla/uniffi-rs/blob/main/CHANGELOG.md

getrandom, renamed getrandom03: kept 0.3.4; latest 0.4.3.
  Calcard uses ahash, which requires getrandom 0.3. This alias enables
  that version's wasm_js backend. Moving the alias to 0.4 would leave
  the 0.3 dependency without its browser backend. Workspace getrandom
  is already on the latest 0.4.3.
